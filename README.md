## ✨ 주요 기능

* **제목 및 본문 한자 훈음(뜻과 소리) 완벽 탑재**:
  * 상단 툴바에서 `[음독]` / `[훈과 음]` / `[숨김]` 3단계 전환 지원
  * 마우스 호버(Hover) 시 팝업 툴팁으로 개별 한자의 대형 글자 및 훈음 즉시 표시
* **모바일 최적화 (Mobile-First Responsive Design)**:
  * 스마트폰 터치 시 화면 하단에 챡 붙는 원터치 한자 훈음 바텀 시트
  * 엄지손가락으로 넘기는 가로 스크롤 작가 필터 칩
  * 화면 크기에 맞춘 유동형 한자 타이포그래피(줄바꿈 방지)
* **구절 페어링 하이라이트 (Interactive Linked Hover)**:
  * 한자 원문 구절이나 현대어 번역 구절에 마우스를 올리면 대구(對句)가 서로 동시에 강조 표시
* **학습 편의 기능**:
  * 실시간 검색 (제목, 한자, 구절, 해석 검색)
  * 글자 크기 조절 (`A-` / `A+`)
  * 테마 선택 (기본 백지 / 한지 韓紙 / 다크 墨)
  * 원문 및 번역 클립보드 원터치 복사
  * 인쇄(Print) 전용 최적화 레이아웃
